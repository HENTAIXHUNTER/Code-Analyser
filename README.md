# Code-Analyser
Code Analyser — Application de bureau Windows (Python/Tkinter) permettant d'analyser et corriger du code source via un modèle de langage local (Ollama, Qwen 2.5 Coder 7B). Chargez un fichier, lancez l'analyse pour obtenir corrections et explications, puis sauvegardez le résultat. Fonctionne hors ligne, sans service cloud.
